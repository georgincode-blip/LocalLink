# Security policy

This repository is an early-stage static prototype and is not ready for production use.

## Reporting a concern
Please do not publish secrets, personal data, or exploit details in a public issue. Contact the repository maintainer privately once a contact method has been added to the project.

## Current limitations
- No authentication or server-side authorization exists.
- No real user data should be entered into the prototype.
- Sample listings are fictional.
- Do not deploy this prototype as a production marketplace without a security and privacy review.
