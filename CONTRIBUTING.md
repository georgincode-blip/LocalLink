# Contributing

Thank you for helping improve LocalLink.

## Before opening an issue
- Search existing issues to avoid duplicates.
- Describe the user problem and the expected outcome.
- Include reproduction steps for bugs.
- Do not include passwords, API keys, personal contact details, or confidential business information.

## Pull requests
- Keep changes focused.
- Explain why the change is needed.
- Test the prototype in a modern browser.
- Check mobile layout and keyboard accessibility.
- Update documentation when behavior or project scope changes.
- Clearly label mock data and incomplete functionality.

## Development
The current prototype has no package manager or build step. Open `prototype/index.html` in a browser to test it.
